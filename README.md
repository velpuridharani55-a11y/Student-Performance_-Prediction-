
##Project Title

Student Performance Prediction System

##Project Objective

To analyze students' academic performance using factors such as attendance, study hours, assignment marks, and examination scores. The project aims to identify performance trends and students who may need additional academic support, helping teachers make better decisions and improve student outcomes.

- <a href="https://github.com/velpuridharani55-a11y/Student-Performance_-Prediction">dataset</a>

##Student Performance Prediction Excel project, you can use these Project Questions and KPIs in your dashboard.

What is the overall student performance?
What is the pass and fail percentage?
How does attendance affect student marks?
Does study time affect academic performance?
Which students are high performers?
Which students are at risk of poor performance?
Which grade is most common among students?
What is the average mark of all students?
Which class/section has the best performance?
How many students need additional academic support?

##insights
1. Start with the correlation table above — whichever factor has the highest correlation with Performance Score is the biggest lever for improving outcomes class-wide.		
2. Use the 'By Risk Level' pivot table (Pivot Summary sheet) to see how many students are High/Medium/Low Risk, and the averages that define each group.		
3. Open Dashboard 2 (Risk Analysis) and Dashboard 9 (Top & Bottom Performers) to get a short list of names to act on this week — the High Risk list and the Bottom 10 table.		
4. Cross-check Dashboards 3-6 (Attendance, Study Hours, Previous Marks, Score Bands) to decide whether an intervention should focus on attendance drives, study-skills coaching, or catch-up classes for weak prior performance.		
5. Re-run this analysis every few weeks: paste new Attendance / Study Hours / Previous Marks into 'Student Data' and every formula, pivot table, and dashboard recalculates automatically.
    
####Final Conclusion

The Student Performance Prediction System successfully analyzes student academic data using Excel. By examining attendance, study hours, assignment marks, and examination scores, the project identifies performance trends and students who may need additional academic support.

The interactive dashboard provides clear KPIs, Pivot Tables, charts, and insights, making it easier for teachers to understand student performance and take timely action. Overall, this project demonstrates how Excel can transform raw student data into meaningful insights and support better educational decision-making.
